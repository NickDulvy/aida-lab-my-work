# Run the notebook — double-click method

## Quick start

**Double-click `Run Notebook.command`** (in the aida-lab-env folder).

- A Terminal window opens and Jupyter Lab starts.
- Your browser opens automatically (or go to http://localhost:8888).
- In the file browser, open **module-03** → **heritage-sites-analysis.ipynb**.
- Run the cells (Shift+Enter or Run → Run All Cells).

No kernel selection. No path pasting. The correct Python environment is used automatically.

---

## First time only

If `Run Notebook.command` says "command not found" for `uv`:

1. Install uv: https://astral.sh/uv
2. In Terminal: `cd aida-lab-env` then `uv sync`
3. Double-click `Run Notebook.command` again.

---

## Editing vs. running

- **Run the notebook**: Use `Run Notebook.command` → Jupyter Lab in browser.
- **Edit the notebook**: Use Cursor (or any editor). You can still edit the .ipynb file in Cursor; changes sync to the file that Jupyter Lab uses.
